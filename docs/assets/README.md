# Documentation assets

The screenshots in this directory come from the **synthetic demo store**, not
from production evidence. They are generated by the Playwright demo setup and
are labelled as synthetic wherever they appear in the README.

Regenerate them from the repository root:

```sh
cd e2e
npm ci
npx playwright install chromium
npm run docs:screenshots
```

The script seeds the demo store, starts the private service on loopback, logs in
with the test-only `demo` token, and writes:

- `private-ui-overview.png`
- `private-ui-run.png`
- `private-ui-benchmarks.png`

It does not use production credentials, AWS, the VM, or live LLM providers.
